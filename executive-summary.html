Executive summary

NO · NOT SAFE TO SUBMIT

There is no downloadable TIF candidate.

The download button is absent because this repository has no model output, official sample grid, holdout result, registry comparison, or validator report. This is deliberate. A generated-looking file is not evidence of a valid submission.

Do not download or submit any file from this repository today. The JSON run card states the same decision and leaves every unmeasured score null.

What a ready artifact must prove

  1. Scientific gate: the selection-bias-aware PU candidate has higher pooled, spatially blocked HOLDOUT-DTI than the local incumbent and no loss in the highest-propensity tercile. Report evaluator version, withheld positives, and 95% CI.
  2. Leakage and uniqueness: every feature passes the feature-alone canary; compare both the score surface and final dots against all registry rasters before placement. A duplicate is logged and stopped, not renamed.
  3. Format gate: read the written GeoTIFF back and verify one float32 band, exact official sample CRS/shape/geotransform/bounds/resolution, finite in-footprint values in [0,1], and null/NaN only outside the footprint.
  4. Provenance: preserve the raster SHA-256, named run card, validator output, unique submission name, short note, and—after a human portal submission—the submission-page receipt.

The format requirements and metric come from the official problem description. The contest describes a single-band float32 GeoTIFF on the training grid, EPSG:32611 at 100 m, values in [0,1], and null/NaN outside the bounds.

How to submit once a future release says “OK TO SUBMIT”

This is a future workflow, not permission to submit the current project state. The current data page requires a DrivenData login; this project does not bypass authentication or submit on your behalf.
  1. Use the site’s top-level download button for the single promoted file only. Verify its displayed filename and SHA-256 against the run card.
  2. Open the DrivenData competition page, sign in, and select New submission.
  3. Under File to submit, choose the downloaded GeoTIFF. The portal accepts a single-band GeoTIFF, or a ZIP containing one GeoTIFF, subject to its displayed format rules.
  4. Enter the short comment associated with that named experiment (for example, a concise method tag). The site's actual candidate note must be no longer than 140 characters under this project's run-card protocol.
  5. Submit through the portal and retain its receipt. Only a score copied from that receipt may be labelled ORGANIZER-CONFIRMED. A public leaderboard entry is not a receipt and a local holdout score is not an organizer score.

Fixing the range error

The portal error Predicted values must be in range [0, 1] means the uploaded pixel values must satisfy the range contract. A future validator must inspect the final on-disk bytes, not only the in-memory model output. Normalize or clip valid in-footprint predictions only, reject NaN/Inf inside the footprint, verify the outside mask, write float32, reopen the file, and compare it to the official template. No candidate exists here, so this error has not been reproduced or fixed in code.
