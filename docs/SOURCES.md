## Scientific and official geospatial sources

| Source | Verified statement | Scope and limitations |
|---|---|---|
| [Bekker & Davis, PMLR 94 (2018)](https://proceedings.mlr.press/v94/bekker18a.html) | Defines positive labels selected conditionally on attributes (SAR) and proposes an EM method. | Assumptions are necessary; this is not a guarantee that a unique absolute propensity surface can be recovered from PU data alone. |
| [Bekker, Robberechts & Davis, arXiv:1809.03207](https://arxiv.org/abs/1809.03207) | Describes an empirical-risk method that incorporates the labeling mechanism and discusses learning when that mechanism is not fully known. | Use the paper to define the statistical estimand and assumptions, not as evidence that this geology application passes holdout. |
| [Giddens & Faulds, 2025 Stanford Geothermal Workshop, SGP-TR-229](https://pangea.stanford.edu/ERE/db/GeoConf/papers/SGW/2025/Giddens.pdf) | The paper reports approximately 91.9% of its identified Great Basin step-overs associated with range-front faults, and explicitly notes the possibility that steep topographic gradients make those settings easier to identify. | This is an association in that study's step-over inventory, not proof that 91.9% of all faults or geothermal systems are range-front faults. The separate “about 25% detailed 1:24,000 mapping” claim was not verified in sources retrieved here and is not used as a fact or scale anchor. |
| [USGS GeoDAWN data release](https://www.usgs.gov/data/geodawn-airborne-magnetic-and-radiometric-surveys-northwestern-great-basin-nevada-and) | Official release describes airborne magnetic/radiometric acquisition and coordinated airborne LiDAR, its study area, products, and CC0 mark. | Does not imply the lidar coverage layer is already included in the competition `training_features.tif`; inspect actual band metadata when data are obtained. |
| [USGS 3DEP Lidar Explorer](https://apps.nationalmap.gov/lidar-explorer/) and [USGS 3DEP Lidar Point Cloud catalog record](https://data.usgs.gov/datacatalog/data/USGS:b7e353d2-325f-4fc6-8d95-01254705638a) | Official public index/data catalog for lidar availability and point-cloud data; catalog record describes public access and public-domain 3DEP products. | No GeoDAWN-aligned mask, download, or intersection test was performed here. Coverage is not a proxy for exhaustive geologic mapping. |
| [USGS Data Series 249: Geologic Map of Nevada](https://pubs.usgs.gov/ds/2007/249/downloads/pdf/DS-249pam_508.pdf) | Describes a public 7.5-minute quadrangle index/grid (the Nevada `NVQDP` quadrangle layer) and map bibliography. | A quadrangle grid identifies map-sheet geography; it does not certify that every sheet was exhaustively mapped for faults. |
| [USGS National Geologic Map Database (NGMDB)](https://ngmdb.usgs.gov/) | Public catalog/map search with individual geologic-map records and scale/area metadata. | Publication records and extents do not by themselves establish complete fault mapping. No complete, validated study-area mask of exhaustively mapped quads was located in this review. |
| [USGS Nevada magnetic and gravity data, DS-234 metadata](https://mrdata.usgs.gov/catalog/cite-view.php?cite=61) and [USGS Great Basin geoscience data base](https://www.usgs.gov/publications/great-basin-geoscience-data-base) | Official gravity/geophysics data products are documented for Nevada/Great Basin. | No selected grid was downloaded, reprojected, or checked for footprint, resolution, units, license, and completeness. These are sources to evaluate if the exact cached basin-fill proxy is absent—not evidence that a ready-to-use covariate is in this checkout. |

## Sibling-site score provenance (not an accepted model result)

- The prompt-reported association of a GEMSDOE32 file named `h33-h33-2-b2-20261004T220000Z-e5eb6e7e-zeros` with `0.2778` is not confirmed by a submission-page receipt in the sources checked.
- The public [GEMSDOE32 manifest](https://github.com/buffedlizard55-lab/GEMSDOE32/blob/main/docs/downloads/submissions_manifest.json) lists that artifact with `receipt: null`; its note marks a projected value as `UNSCORED`. The sibling repo's [PR #9](https://github.com/buffedlizard55-lab/GEMSDOE32/pull/9) describes H33-2-B2 as a removal/pruning arm and reports an owner-generated projection. This evidence is about that repository's own account, not independent organizer confirmation.
- The official public leaderboard's displayed `0.2778` entry is associated with `extradr19`, not with a linked raster filename. A numerical match alone cannot establish that it is the H33 file. The mismatch is recorded as an irregularity; no explanation of a competition result is asserted without a receipt.
- The long score list in the user request is useful as user-reported context, not a verified submission registry. Blank scores remain blank; future-dated entries are not treated as current evidence. No previous TIFF has been copied into this repo.

## Evidence labels used by the project

- **HOLDOUT-DTI:** only a locally executed blocked hide-and-recover evaluation, naming evaluator version, withheld positives, and 95% CI.
- **ORGANIZER-CONFIRMED:** only a value copied from an actual submission-page receipt tied to a specific file.
- **PUBLIC LEADERBOARD DISPLAY:** official public table snapshot; useful context but neither of the above.
- **OWNER-REPORTED / PROJECTED / UNVERIFIED:** third-party repository claims without a relevant receipt or local reproducible evidence.
- **NOT RUN / NOT AVAILABLE:** no result; never substitute a projection or fabricated estimate.
