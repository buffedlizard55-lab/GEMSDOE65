## Fixed experiment

- Primary scenario: assumed propensity **at the training-covariate reference point** e(z=0)=0.50. Sensitivities: 0.25 and 0.75. These are assumptions, not measured regional completeness or the user's quoted mapping percentage.
- At most three fits/experiments (one per scale scenario, each includes four folds and its nnPU comparator). Two-hour session budget. No parameter search and no selection of the best sensitivity after seeing results.
- Propensity covariates only: local relief, slope, negative isostatic gravity (basin-fill **proxy**, not depth), binary lidar data coverage, log distance to a label-free slope/relief terrain-front **proxy**.
- Outcome features: those five covariates plus cached physical bands 3, 18, 11, 12, 19, 15, 17. No coordinates, catalogue distances, map labels, prior predictions or hidden truth as features.
- Median imputation, robust scaling, and quadratic expansion fit on training pixels only. Missingness is disclosed; no template prediction values become a feature.
- Use the PMLR SAR-EM posterior q=1 for labeled positives, q=f(1-e)/(1-fe) otherwise; fit fractional-label logistic outcome and q-weighted selection models. Hold the propensity intercept at the assumed reference value to expose non-identifiability. No local-certainty claim; decay d=1. This is a constrained sensitivity variant, not an exact reproduction of every PMLR hyperparameter.
- Refit outcome using Bekker–Robberechts–Davis empirical risk E[loss0 + s min(1/e,10)(loss1-loss0)], logistic loss and fixed L2 regularization. Weight clipping deliberately introduces bias; log its prevalence. Compare with actual nonnegative PU risk, with marginal-population sampling and the same corrected positive mass as prior, on identical folds/features/regularization.
- Reuse the immutable shared template from 58GEMSDOE. Its `spatial.folds` withholds whole 8-connected catalogue components touching each label-blind spatial quadrant and excludes an 8 km training buffer. Components are raster proxies, not independently identified geological fault systems. Mask visible faults pixel-exactly. No catalogue-derived features are used.
- Leakage canary: each input alone against withheld positives and catalogue-zero proxies; test both directions, halt if AUC >0.90. No AUC is a competition score.
- Primary HOLDOUT-DTI is the continuous normalized output (no placement tuning), pooled via shared `evaluate_holdout.py`: alpha .2, beta .8, triangular kernel 300 m. Paired 20 km block bootstrap, 1,000 draws, 95% CI. CI is conditional on these fits and does not capture catalogue selection bias.
- Highest-propensity tercile uses the training-population weighted 2/3 quantile of fitted e; identical restricted evaluation domain for both arms. It is a stratum-domain diagnostic, not an independently identified true propensity class.
- Promote only if primary pooled DTI is strictly higher than nnPU, its paired lower confidence bound is positive, and high-propensity-tercile difference and its lower confidence bound are nonnegative. Any missing comparable incumbent blocks promotion; no historical proxy/translated-truth number substitutes for a matched holdout best.
- Uniqueness uses the inherited literal gate (>0.90 rank correlation or >0.70 forward support overlap within 3 pixels). Check surface before any placement; stop immediately on a duplicate witness. A saturated continuous prior is NOT silently exempted. Incomplete registry cannot pass. Renaming/recompression/NaN changes cannot establish pixel uniqueness.
- No real competition upload. A qualifying candidate goes only to a separate selector; weekly cap must be checked on the submission page, not guessed. TIFF download is disabled on any failure.
