How to submit a GEMS GeoTIFF — and whether this project has one ready

Read the gate at the top of the status page first. This page gives the exact upload steps and the format contract. It submits nothing on your behalf.

Cleared to submit

There is one approved file. Download gems65-sar-em-propensity-half-20261011T223500Z-5e4660cd-zeros.tif, paste the note below into the Note (optional) field, and submit. Do not rename the file. Verify the sha256 in the table at the bottom of this page after downloading.

Step 1 — confirm the gate is green

  1. The status page must show Cleared to submit and name the exact candidate from the run card. A research note, a projected score, an old file, or a format-only check is not promotion.
  2. The run card must contain the evaluator version, withheld-positive count, HOLDOUT-DTI with a 95% CI, the registry correlation / dot-overlap result, the raster sha256, and passing validator output. The candidate must beat both the current holdout best and the matched nnPU baseline overall and must not lose in the highest-propensity tercile.
  3. If any of those is missing or failed: stop. Do not substitute a sibling project's raster.

Step 2 — download the file

  1. Open the downloads page and use the primary *-zeros.tif link. That variant writes 0.0 outside the footprint with nodata=None, so all 12,279,160 cells satisfy 0 ≤ v ≤ 1 and there is no NaN anywhere. This is the variant that removes the DrivenData error "Predicted values must be in range [0, 1]", which is raised when the validator's range test sees a NaN comparison return False.
  2. A *-nan.tif variant that reproduces the sample submission's NaN-outside convention is published alongside it for byte-format comparison. Prefer the -zeros file for upload.
  3. Do not rename, repackage, or re-clip the file. Preserve the sha256 and the note shown for that exact run.

Step 3 — upload it

  1. Sign in at drivendata.org/competitions/306/competition-doe-gems and open the submissions page. Choose New submission.
  2. Under File to submit, choose the downloaded .tif. The form accepts a single GeoTIFF or a ZIP containing exactly one GeoTIFF; upload the direct .tif.
  3. In Note (optional), paste the short note from the run card (kept under 140 characters by this project), e.g. GEMSDOE65 SAR-EM propensity PU (Bekker-Davis 2018 + BRD 2019 risk, w=1/e^0.5 clip 10) vs nnPU, identical buffered folds; 39802 dots; holdout.
  4. Confirm the filename, note, checksum, and green gate all describe the same run, then submit.
  5. Save the organizer's submission-page receipt. Only a receipt tied to the exact file/hash counts as ORGANIZER-CONFIRMED evidence in this project.

Format contract (what the validator checks)

  • exactly one band, float32;
  • EPSG:32611, 100 m, shape 3730 × 3292, transform (100, 0, 243350, 0, -100, 4508550) — identical to the official sample_submission.tif;
  • every in-footprint value finite and in [0, 1];
  • no NaN inside the footprint; NaN (or 0.0) only outside it;
  • a separate read-back of the written bytes reproduces the same receipt.
