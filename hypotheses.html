1 · Terrain/coverage SAR-EM
Top validation candidate		 Local relief, slope, LiDAR coverage, distance to range front, gravity-derived basin-fill proxy in the propensity model. Signature: a spatially varying label-observation/visibility surface, not a fault edge. Corrects over-representation of accessible, exposed faults so less-visible positive examples can influence the classifier. Mimics: lithologic contacts, erosional scarps, basin margins, and correlated mapping access. First SAR-EM versus nnPU experiment in this checkout; the repo has no existing model. Expected direction: moderate potential, unmeasured. Cost: low-to-medium only if the shared cache and tools already contain the exact bands; currently blocked.
2 · Quadrangle-anchor scale calibration Official 1:24,000 map extents and 7.5-minute quadrangle index, but only where mapping completeness is documented. Signature: label-density/coverage discontinuity across map footprints. An independently documented exhaustive map could anchor propensity scale. Mimics: mapping effort driven by access/population/geologic interest; map-sheet presence mistaken for completeness. Tests absolute scale calibration rather than another predictor. Expected direction: potentially high only if a true exhaustive anchor exists; otherwise none. Cost: high. Not currently viable as an anchor: no exhaustive full-footprint completeness mask was verified.
3 · LiDAR-availability selection audit USGS 3DEP LiDAR availability/footprint, local relief, slope. Signature: a change in label visibility at acquisition boundaries after terrain matching. May reveal a mapping-propensity shift between high- and lower-resolution surface observations. Mimics: acquisition targeting, roads, channels, and erosional scarps. Uses coverage as an observation covariate, not raw LiDAR lineaments as faults. Expected direction: low-to-moderate, unmeasured. Cost: medium; public index is identified but no aligned mask was retrieved.
4 · Basin-fill-conditioned propensity sensitivity Gravity-derived basin-fill proxy interacted with range-front distance and terrain covariates in e(x). Signature: possible observability differences under/along basin cover. May correct under-recording where cover obscures surface traces without treating gravity edges as faults. Mimics: density/lithology contrast and basin geometry without a fault. Keeps the gravity layer within the selection model and reports sensitivity; no standalone geophysical scoring. Expected direction: uncertain. Cost: medium-to-high; requested proxy and shared feature stack are absent.

Why candidate one is first

The published SAR-EM method directly addresses covariate-dependent positive-label selection, and the Great Basin step-over literature explicitly raises topographic detectability as a source of bias. The first test can compare the propensity-aware empirical risk with nnPU on the same frozen spatial holdouts without using a competition slot. This is the best value-of-information experiment, not a claim it will win.

Gate before any submission slot

  1. Run feature-alone leakage AUC tests; any AUC above 0.90 is treated as leakage until explained.
  2. Withhold entire fault segments with a buffer, derive catalogue features from visible faults only, and mask visible faults pixel-exactly.
  3. Compare pooled DTI with alpha 0.2, beta 0.8 and 300 m support; report evaluator version, withheld-positive count, and 95% CI.
  4. Require higher overall holdout DTI and no loss in the highest-propensity tercile.
  5. Compare the prediction surface and final dots against every prior registry raster before publication.
