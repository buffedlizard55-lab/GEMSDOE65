1 · test first
Highest plausible value		 Terrain visibility drives fault inclusion.
Local relief, detrended-elevation slope, DEM-source coverage (1 m GeoDAWN lidar versus coarser 3DEP where verified), and distance to an independently mapped range-front break; model the labeling propensity with SAR-EM.		 Scarp-scale relief and steep topographic gradients make some fault strands easier to identify. The test is whether catalogue inclusion varies with visibility after conditioning on being a fault. Faults in low-relief, poorly surveyed terrain may be real but absent from the catalogue. This is an observation-process hypothesis, not a claim that relief creates faults. The proposed novelty is correction for which faults enter the catalogue, rather than a direct ridge/scarp score. This checkout contains no implementation. A listed sibling site (20GEMSDOE) already describes SAR-nnPU and PU-proxy experiments, so generic PU/SAR is not new; the explicit visibility-covariate propensity model and a defensible mapping-coverage anchor are the potentially distinct pieces. The full sibling code/history is not audited, so global novelty is unverified. Cost: high—the segment folds, one-feature leakage checks, propensity estimation, clipped-risk training, and matched nnPU comparison must all be run with the shared tools.
2
Moderate–high plausible value		 Detailed-map effort anchors propensity.
NGMDB geologic-map publication footprints and scale metadata joined to the USGS 7.5-minute map-index polygons; use map availability only as an inclusion/effort covariate.		 The signature is the map-production footprint and map scale—not a geologic lineament. Faults in quadrangles lacking detailed mapping may be less likely to appear in the labelled catalogue, even when their geomorphology is comparable. This could anchor the *relative scale* of the SAR propensity only if the inventory is shown to be sufficiently complete and accurately georeferenced. Unlike terrain-only visibility, this models deliberate survey/mapping effort. USGS publishes a free 7.5-minute grid index and NGMDB map catalogue, but the grid is not a geologic-coverage layer and catalog extents can overstate actual mapped area. Completeness must be audited; otherwise keep the propensity unanchored and run sensitivity analyses. Cost: medium–high—metadata joins and scale/footprint QA are needed.
3
Moderate, coverage-dependent		 Basin fill obscures fault expression.
Provided isostatic-gravity anomaly and its slope, plus a gravity-derived depth-to-basement/basin-fill proxy only where its footprint is confirmed to overlap the competition region; condition on relief and verified DEM-source coverage.		 A broad gravity low / basin-depth increase and basin-edge gradient can mark thick basin fill, where surface scarps may be muted or absent. The hypothesis is that detection propensity falls under concealment; it is not that every gravity edge is a fault. Missing faults would be expected around buried basin margins or within filled basins. Prior shared-site names include gravity/geophysics prediction experiments. The distinction here is using basin fill as an observation/visibility covariate in the propensity model, not emitting the gravity gradient as a fault prediction. The free USGS gravity-based depth-to-basement release is obtainable from its public ScienceBase listing, but it is a regional eastern-Great-Basin product at coarse scale; its bounding box does not prove raster overlap with this northwestern study footprint. Cost: high—exact coverage intersection, resolution, and provenance must be audited before use.
4
Moderate, nested in priority 1		 Range-front association changes visibility, not just geology.
Distance to an independently derived range-front break, local relief, and slope; avoid deriving the propensity feature from held-out catalogue traces.		 At range fronts, strong relief may expose fault scarps and create a mapping preference; basin-interior or subtle relay structures can be missed. Giddens & Faulds report a strong range-front association among identified step-overs and explicitly discuss visibility bias. The test asks whether the apparent association attenuates after correcting for observability. Earlier H33-labelled work focuses on step-over/relay geometry; this sub-hypothesis uses range-front distance to explain label selection and forbids using hidden-fault labels to build the feature. It is not independent of priority 1, so it must be evaluated as a predeclared ablation, not counted as an independent win. Cost: medium if a label-independent range-front layer already exists; otherwise high.

Comparison protocol for the top candidate

  1. Use the same spatial folds and whole-segment buffers for SAR-EM and nnPU; no random-pixel split.
  2. For each covariate alone, run the feature-only leakage canary. Any AUC above the stipulated threshold is treated as leakage until demonstrated otherwise.
  3. Estimate e(x)=P(labelled | fault, x) with SAR-EM on the predeclared low-dimensional propensity set. If there is no defensible quadrangle anchor, report a sensitivity family rather than a calibrated propensity.
  4. Train the requested propensity-aware empirical risk, cap inverse-propensity weights at 10, and compare with nnPU on identical folds.
  5. Use the shared hide-and-recover evaluator: derive catalogue features from visible faults only; mask visible-fault pixels exactly; compute pooled distance-weighted Tversky with the official kernel/weights; report evaluator version, withheld-positive count, and 95% CI.
  6. Require improvement over both the current holdout best and the matched nnPU baseline overall, plus no loss in the highest-propensity tercile. If the current best is unavailable, stop promotion. Then perform registry correlation and dot-overlap checks both before placement and on final dots. A failed/untested gate is negative, not a reason to submit.

The current run card records the measured outcome: the propensity-weighted estimator is a null against its matched nnPU baseline on the blocked hold-out (Δ = +0.0018, 95 % CI [−0.0060, +0.0111]), while the declared splay-band × range-front rule is a positive (0.0165 [0.0120, 0.0211] vs nnPU 0.0061 [0.0010, 0.0119]).
