Research & score audit

What the target means

The official task is to map geological faults that are indicative of geothermal resources. It is not a direct geothermal-vent detection task. A high public metric value is not itself a geological explanation: the official distance-weighted Tversky score rewards probability mass near newly labelled fault pixels, and the false-negative weight exceeds the false-positive weight. This motivates carefully tested recall, calibration, and spatial support—not arbitrary density or a claim of geothermal causality.

Why selection-bias-aware PU learning is a rational lane

Let Y=1 denote a real fault and S=1 a catalogue label. Under selected-at-random (SAR) PU learning, e(x)=P(S=1 | Y=1,x) can depend on observed attributes. Bekker and Davis propose SAR-EM under assumptions about a known subset of propensity attributes; Bekker, Robberechts and Davis develop an empirical-risk method that accounts for selection bias. The assumptions are substantive: with unknown fault prevalence and unknown labelling propensity, positive–unlabeled data alone do not uniquely determine an absolute selection probability. If a defensible exhaustive-map anchor cannot be verified, show sensitivity over propensity scale rather than presenting one scale as identified.

The Great Basin study by Giddens and Faulds reports a strong range-front association for step-overs and explicitly notes that steep terrain can make those structures easier to identify. That makes an observability mechanism scientifically testable. It does not establish the same bias for all fault types or all catalogue sources, and it does not verify the separate 25% detailed-mapping claim.

  • Official public leaderboard display (not HOLDOUT-DTI and not a submission-page receipt): the row showing 0.2778 was under participant extradr19 when the official page was checked, not a raster filename. The public table does not link the row to the GEMSDOE32 file.
  • Sibling-repository owner-generated manifest (not an organizer receipt): the GEMSDOE32 entry for the named TIFF has receipt: null. Its note describes a projected value and calls the artifact unscored.
  • Sibling-repository PR description (owner-reported analysis): H33-2-B2 is described as a pruning/removal arm, not a new trained geology model; its projected/live-mirror analysis is not an organizer-confirmed score.

Conclusion: the premise that this exact TIFF earned that public score is not verified. The cause of the mismatch is unknown, so this project does not invent a causal “why.” The numeric match to another participant is not proof that participant submitted this artifact.

Is a score above the prompt's old reference possible?

In principle, yes: the live official board currently displays public entries above the user-reported 0.3195 reference. That is evidence only that higher public leaderboard results exist; it is not evidence that SAR-EM will achieve them, nor a substitute for the private test or expert-reviewed final round. This checkout has no data, model, incumbent holdout result, evaluator, registry, or raster. Therefore no score projection is defensible and the current answer for this repository is **no submission now**.
