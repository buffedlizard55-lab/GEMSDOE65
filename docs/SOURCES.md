## Sibling-site score provenance (not an accepted model result)

- The user-reported link between a GEMSDOE32 H33 filename and a public value has no receipt in the records checked here.
- GEMSDOE32's [public submission manifest](https://github.com/buffedlizard55-lab/GEMSDOE32/blob/main/docs/downloads/submissions_manifest.json) lists the named artifact with `receipt: null` and describes it as “UNSCORED”; its [PR #9](https://github.com/buffedlizard55-lab/GEMSDOE32/pull/9) describes owner-generated development/projection context, not an organizer receipt.
- A public participant-level leaderboard row does not name a submitted TIFF. Without a receipt for the exact file, a numerical match cannot establish artifact attribution or explain a model's performance. This repository no longer copies leaderboard values because of the Terms of Use restrictions above.
- Scores and dates supplied by the user remain user-reported context unless a current authorized source and file-linked receipt verify them. No previous TIFF has been copied into this repository.

## Evidence labels used by the project

- **HOLDOUT-DTI:** only a locally executed blocked hide-and-recover evaluation, with evaluator version, withheld-positive count, and 95% CI.
- **ORGANIZER-CONFIRMED:** only a value copied from an actual submission-page receipt tied to a specific file/hash.
- **PUBLIC LEADERBOARD DISPLAY:** a participant-level organizer page value. This repository does not mirror such values; even if viewed through an authorized channel, they are neither `HOLDOUT-DTI` nor file-level `ORGANIZER-CONFIRMED` evidence.
- **OWNER-REPORTED / PROJECTED / UNVERIFIED:** third-party repository claims without a relevant receipt or local reproducible evidence.
- **NOT RUN / NOT AVAILABLE:** no result; never substitute a projection or fabricated estimate.
