Rejected hypothesis: excluding the 3 px halo around known faults

The metric zeroes predictions on the catalogue and credits each dot only against non-catalogue truth, so a dot inside the halo is an expensive false positive. The hypothesis was that forbidding the halo would pay. It does not:
