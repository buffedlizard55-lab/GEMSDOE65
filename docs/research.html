Fixed experiment

  • Primary scenario: assumed propensity at the training-covariate reference point e(z=0)=0.50. Sensitivities: 0.25 and 0.75. These are assumptions, not measured regional completeness or the user's quoted mapping percentage.
  • At most three fits/experiments (one per scale scenario, each includes four folds and its nnPU comparator). Two-hour session budget. No parameter search and no selection of the best sensitivity after seeing results.
  • Propensity covariates only: local relief, slope, negative isostatic gravity (basin-fill proxy, not depth), binary lidar data coverage, log distance to a label-free slope/relief terrain-front proxy.
  • Outcome features: those five covariates plus cached physical bands 3, 18, 11, 12, 19, 15, 17. No coordinates, catalogue distances, map labels, prior predictions or hidden truth as features.
  • Median imputation, robust scaling, and quadratic expansion fit on training pixels only. Missingness is disclosed; no template prediction values become a feature.
  • Use the PMLR SAR-EM posterior q=1 for labeled positives, q=f(1-e)/(1-fe) otherwise; fit fractional-label logistic outcome and q-weighted selection models. Hold the propensity intercept at the assumed reference value to expose non-identifiability. No local-certainty claim; decay d=1. This is a constrained sensitivity variant, not an exact reproduction of every PMLR hyperparameter.
  • Refit outcome using Bekker–Robberechts–Davis empirical risk E[loss0 + s min(1/e,10)(loss1-loss0)], logistic loss and fixed L2 regularization. Weight clipping deliberately introduces bias; log its prevalence. Compare with actual nonnegative PU risk, with marginal-population sampling and the same corrected positive mass as prior, on identical folds/features/regularization.
  • Reuse the immutable shared template from 58GEMSDOE. Its spatial.folds withholds whole 8-connected catalogue components touching each label-blind spatial quadrant and excludes an 8 km training buffer. Components are raster proxies, not independently identified geological fault systems. Mask visible faults pixel-exactly. No catalogue-derived features are used.
  • Leakage canary: each input alone against withheld positives and catalogue-zero proxies; test both directions, halt if AUC >0.90. No AUC is a competition score.
  • Primary HOLDOUT-DTI is the continuous normalized output (no placement tuning), pooled via shared evaluate_holdout.py: alpha .2, beta .8, triangular kernel 300 m. Paired 20 km block bootstrap, 1,000 draws, 95% CI. CI is conditional on these fits and does not capture catalogue selection bias.
  • Highest-propensity tercile uses the training-population weighted 2/3 quantile of fitted e; identical restricted evaluation domain for both arms. It is a stratum-domain diagnostic, not an independently identified true propensity class.
  • Promote only if primary pooled DTI is strictly higher than nnPU, its paired lower confidence bound is positive, and high-propensity-tercile difference and its lower confidence bound are nonnegative. Any missing comparable incumbent blocks promotion; no historical proxy/translated-truth number substitutes for a matched holdout best.
  • Uniqueness uses the inherited literal gate (>0.90 rank correlation or >0.70 forward support overlap within 3 pixels). Check surface before any placement; stop immediately on a duplicate witness. A saturated continuous prior is NOT silently exempted. Incomplete registry cannot pass. Renaming/recompression/NaN changes cannot establish pixel uniqueness.
  • No real competition upload. A qualifying candidate goes only to a separate selector; weekly cap must be checked on the submission page, not guessed. TIFF download is disabled on any failure.

A defensible mechanism, not a causal attribution

In the protocol's DTI, weighted true-positive credit saturates per truth pixel. Dense/redundant emissions can accumulate false-positive mass without providing additional truth coverage. Removing a redundant dot that contributes false-positive mass can therefore improve the ratio. A catalogue-flank exclusion can suppress mapped-fault continuations that receive no new-fault credit. That is a plausible reason the pruning helped; we cannot identify which removed dots were genuine organizer false positives without hidden truth or a receipt-backed controlled ablation.

For binary dots, let T be total truth coverage, M total dot self-credit, n the dot count, and K the truth count. With alpha+beta=1, D = alpha(T+n-M)+beta K. Removing a dot loses truth credit deltaT and removes false-positive mass f.

Exact removal derivation: before removal, D=T+alphaFP+beta(K-T). After removal, T'=T-deltaT and FP'=FP-f, so D'=D-(1-beta)*deltaT-alpha*f. Provided the denominators are positive, the ratio improves exactly when

alpha*f*DTI > deltaT * (1-(1-beta)*DTI).

This keeps loss of coverage separate from removal of FP mass. Keeping a redundant dot with deltaT=0 and f>0 lowers the score whenever T>0; removing it improves the ratio. The expression does not assume T=M or convert a claimed leaderboard number into a prediction.

Selection bias: the crucial scientific distinction

With PU observations, P(S=1|x) = e(x) * P(Y=1|x). Many pairs (e,f) can produce the same observed product. A small propensity feature set is a structural modeling restriction, not an empirical identification certificate. The PMLR paper additionally discusses local certainty; it is not established in these geophysical rasters. We therefore fixed the selection-model intercept at three preregistered reference values and made no claim that they estimate regional mapping coverage.

The user's quoted Great Basin range-front/mapping percentages were not independently recovered from the primary Stanford paper. They motivate a question, not a fitted numerical anchor. A public map index describes map products; it does not automatically certify that all faults in a quadrangle were found. No verified exhaustive-quadrangle anchor exists in this run.

The paper's exact E-step was implemented. Fractional-label outcome and posterior-weighted selection M-steps were used with an explicitly fixed reference propensity. A clipped inverse-propensity risk and genuine nnPU comparator used the same sampling weights, covariates, spatial folds, regularization, and corrected positive mass. Bounded logistic coefficients prevent unbounded signed-risk optimization. Clipping intentionally trades bias for stability. Tests verify analytic gradients, risk identities, nonnegative-risk clamping, and posterior probabilities.

All twelve fold/scenario EM fits reached the fixed iteration cap. Inner optimizers converged, but the EM stopping criterion did not. Results are explicitly finite-iteration negative results, not converged propensity estimates. No extra model experiment or tuning was performed after the three-scenario budget. The executed numeric settings and the preregistration-detail gap are recorded in research/implementation_details.md.

Validation discipline and its limits

  • Four shared label-blind spatial quadrants; full 8-connected components touching the test quadrant are excluded from training, including their tails.
  • An 8 km spatial training buffer; visible catalogue is masked pixel-exactly by the shared evaluator.
  • No catalogue-derived predictors. Imputation/scaling fit only on training samples; stratified positive/unlabeled samples carry population-correcting weights.
  • All twelve physical features individually tested in each fold before fitting; the canary did not trigger. Pass 2 also checked every standardized/quadratic basis (144 checks) on the same samples without refitting; this was an after-fit diagnostic on an already-negative result. Passing the canary is not proof that all leakage is impossible.
  • Pooled distance-weighted terms, not a mean of fold ratios. Paired 20 km spatial-cluster bootstrap and conditional confidence intervals.
  • Highest-propensity tercile defined by each training population, never by holdout label optimization. Restricting the spatial evaluation domain to this tercile can truncate a 300 m neighborhood; both arms use the same restriction, and it is a diagnostic rather than a globally additive decomposition.
  • The observed catalogue is itself selection biased. Hide-and-recover validates recovery of mapped faults, not transport to the organizer's unmapped-fault population. Withheld catalogue zeros are unlabeled, not verified negatives.
  • No portable comparable-incumbent holdout receipt was established. Historical shifted-truth/live-mirror projections cannot stand in for this evidence.

Executed configuration (recorded after the run, not retroactive preregistration)

  • Three reference-propensity scenarios: primary 0.50, sensitivities 0.25 and 0.75.
  • Four shared spatial folds; 80-pixel (8 km) training exclusion, including whole-component tails.
  • Training sample per fold: up to 6,000 labeled positives and 30,000 catalogue-complement pixels, without replacement. Population-correcting weights make these a marginal-population expectation, not a balanced empirical prevalence.
  • Sampler seeds: 651100–651103; identical samples/designs across scenarios and comparator.
  • Twelve physical covariates; outcome basis: intercept, clipped robust-standardized covariates, and one-quarter squares (25 coefficients). Propensity basis: first five covariates only, with a fixed assumed intercept.
  • EM initialization: constant class probability observed-positive fraction / reference propensity; propensity slopes initially zero.
  • EM E-step: exact posterior with no local-certainty decay (d=1).
  • Fixed 25-iteration EM cap; convergence requires at least five iterations and population-weighted mean absolute propensity change below 1e-4. This did not occur in any fold/scenario.
  • M-step and risk optimization: SciPy L-BFGS-B, fixed L2 1e-4, coefficient bounds [-20,20], maximum 150 inner iterations, ftol 1e-10, gtol 1e-6. Inner optimizers succeeded.
  • Final signed-risk target: s * min(1/e,10). nnPU prior is the same sample's population-weighted corrected positive mass. nnPU minimizes the nonnegative-risk objective directly; it does not implement the stochastic reverse-gradient training schedule.
  • Inference: sigmoid confidence in [0,1], float32; no min–max stretch of the TIFF. Only the illustrative PNG is contrast-stretched.
  • Pooled block bootstrap: 1,000 draws, seed 651011, 20 km cells, same block draws for both arms, integer truth-count equality checked.
  • Original pre-fit canary: each of the twelve physical covariates in each fold. Pass-2 audit: 144 raw/standardized/quadratic checks with identical training samples, no refitting. Future runner now performs all of them before training.
