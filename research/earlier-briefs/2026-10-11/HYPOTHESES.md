**Status:** proposals only. No model, holdout, or raster was run. The current repository has no model implementation, so each item differs from what is implemented here (there is nothing to compare against). The available sibling-site result list is user-provided and incomplete as an implementation inventory; therefore **novelty across all GEMSDOE projects is not established**. Do not describe these as proven-new methods.

All candidates stay inside the requested selection-bias-aware PU lane. They test how catalogue labels were selected or how that selection can be anchored; they are not permission to build a separate lineament/dot-placement model. Expected improvement is qualitative, explicitly unmeasured, and not a score projection.

## Ranking and decision

Rank 1 is the only candidate authorized for the first experiment. It has the strongest direct connection to the cited selection-bias mechanism and can be tested against nnPU without spending a submission slot. This is a **priority order**, not a claim that it will improve DTI. The 1:24,000 coverage anchor is scientifically valuable only after completeness is proven; the map catalog alone cannot identify “exhaustive” quads.

### Top-candidate experiment (not run; exact preregistration)

1. Obtain official training features, labels, sample grid, and the shared cached stack; record hashes. Obtain the existing template's holdout evaluator, writer, and validator—do not fork them.
2. Freeze identical spatial blocks and seeds for nnPU and SAR-EM. Withhold whole fault segments with a buffer; derive catalogue features only from visible faults; remove visible positive pixels exactly. Keep all preprocessing inside each fold.
3. Run a single-feature AUC leakage canary before fitting the multivariable model. AUC above 0.90 is a fail pending proof that the feature does not encode withheld labels.
4. Fit SAR-EM using only the preregistered propensity covariates. Report identifiability assumptions and sensitivity to propensity scaling. Use propensity-aware empirical risk with inverse weights capped at 10; use the same folds and training budget for the nnPU comparator.
5. Compare pooled holdout DTI (alpha 0.2, beta 0.8, 300 m triangular kernel), paired block-bootstrap 95% CI, and DTI in the highest-propensity tercile. Record withheld-positive counts and evaluator version. Do not substitute a projection or the public leaderboard.
6. Proceed to surface/placement only if overall blocked DTI is higher than the incumbent holdout best and the highest-propensity tercile has no loss. Compare the surface and final dots against every registry raster before publishing. If any prerequisite is absent, record `NOT_RUN` / negative, not a fabricated result.
