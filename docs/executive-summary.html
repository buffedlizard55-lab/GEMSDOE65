The submission checklist

01

Confirm a released candidate exists

The top of this site must explicitly show research promotion and a TIFF download linked to a matching SHA256. This run does not. A static website cannot train or safely invent a prediction file in your browser.

02

Obtain separate selector clearance

Read the live competition rules and submission page. Verify the remaining weekly allowance there; it is unknown here. Log the selector’s decision.

03

Download only the approved TIFF or one-TIFF ZIP

Do not upload this website, a JSON run card, an HTML report, the example raster, or an old submission. Preserve the unique filename and compare its SHA256 to the release receipt.

04

Run the local validator against the exact file

Use python scripts/validate_submission.py path/to/approved.tif. A pass checks representation, not hidden-label performance or organizer acceptance. Any failure blocks upload.

05

Enter the competition’s “New submission” form

After selector clearance, choose the approved TIFF (or single-TIFF ZIP) under “File to submit.” Use the release’s unique name and note of at most 140 characters. Review the current form; it was not accessed in this session.

06

Keep the actual organizer receipt

Only the submission-page receipt can establish acceptance and an ORGANIZER-CONFIRMED score. Record receipt URL, name, file hash, note, date and displayed result. Never replace it with a local projection.
