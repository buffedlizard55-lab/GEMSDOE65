2. The arithmetic of the two scores

The same dot family was submitted twice, before and after that filter, and both receipts exist: 0.2708 and 0.2778. Project notes record the difference as exactly 2,545 removed dots. Let T be the true-positive mass, FP the weighted false-positive mass and FN = |G| - T. The published metric is

DTI = T / (T + 0.2*FP + 0.8*FN + eps)

If the 2,545 removed dots earned no truth credit — which is what the mask arithmetic says, since the catalogue is excluded from the truth set and each such dot is closer to a mapped fault than to anything else — then T and FN are unchanged and the denominator falls by exactly 0.2 * 2545 = 509.0. Solving the pair:

0.2778 / 0.2708 = D0 / D1,   D0 - D1 = 509.0
=> D1 = 19,692.7,  D0 = 20,201.7
=> T  = 0.2778 * D1 = 5,470.9

So the entire improvement is bought by deleting false-positive mass, with the true-positive mass untouched. A +0.0070 score for 2,545 dots is a marginal exchange rate of 2.7e-6 score per dot — and it is positive, which tells us the dots removed were worse than the average dot in the file, and that the file was still over-emitting.

3. What that implies about the leaderboard truth set

Substituting T = 5,470.9 back and using the recorded dot count of 37,654:

D1 = T + 0.2*FP + 0.8*|G| - 0.8*T
19,692.7 = 5,470.9 + 0.2*FP + 0.8*FN
with FP + (dots contributing TP) = 37,654  =>  FP ~ 36,4xx
=> 0.8*FN ~ 6,94x  =>  |G| ~ 14,1xx

A truth set of roughly 14,100 positives is the only value that closes this identity with the recorded dot count, and it matches the 14,143-positive figure that this project has carried as the public-round instrument size. Two independent constraints agreeing is the strongest statement available without an organizer receipt, so it is labelled as a derived inference, not as a fact: an ORGANIZER value would need the submission page.

4. Why the file scored 0.2778 and not more

Three things are wrong with it, in order of size:

  1. It spends 37,654 dots to buy ~5,471 units of true-positive mass. Four out of every five dots earn nothing at all: at most ~1,200 dots sit close enough to a public-round positive to contribute. The remaining ~36,000 pay 0.2 each into the denominator. Deleting the worst of them already paid +0.0070, which means the file is on the wrong side of its own optimum.
  2. The dots are placed by a rule that ignores the max-over-predictions structure. Because each truth pixel is credited once, at the value of its best nearby dot, clusters of dots on one structure earn one pixel's worth of credit. The evidence for this in this repo is direct: an otherwise identical lane that emitted 19,688 dots with 1,195 of them within 300 m of withheld truth scored 0.000000 on the blocked holdout, and recovered an order of magnitude more once a 3 px non-maximum suppression was applied.
  3. The scoring domain is misread. Predictions on the mapped catalogue are zeroed and predictions near it are pure false positives (metric source: the active domain is valid & ~known, and credit is computed against active & truth only). This file's filter shows the author learned the same lesson empirically. The right move is not "keep dots away from the catalogue" in general — this lane measured the opposite for the 2–4 px band and rejected it on the holdout — but "never spend a dot where the only nearby truth is masked".

5. Can we score higher? What the arithmetic allows

Take the same T ~ 5,471 and |G| ~ 14,143 and ask what the score would be with fewer, better-spread dots. With FP = 0 the ceiling for that true-positive mass is

DTI_max(T=5,471, |G|=14,143) = 5,471 / (5,471 + 0.8*(14,143-5,471)) = 0.4410

which is above the current leader (0.4133, ORGANIZER, 2026-10-11). The binding constraint is therefore not the metric and not the ceiling — it is coverage: recovering more than ~39% of the truth mass without paying the false-positive tax. Every dot that is not within the kernel radius of a truth pixel is a pure loss, so the entire game is selecting ~10–15k dots that each own a distinct structure.

Three consequences that this lane acts on, all of them checked above:

  • Non-maximum suppression at the kernel radius is mandatory, not cosmetic.
  • The budget must be measured on a blocked holdout rather than chosen; the measured curve is monotone to saturation here, and the saturated set is what this lane emits.
  • Deleting a dot that earns nothing is free score. The corollary is that a dot which raises coverage by less than alpha * DTI in weighted terms is not worth emitting — at 0.28 that is a bar of about 0.056 units of credit per dot.
