Start with the evidence, not the filename

The official task is fault prediction. Ground truth is incomplete, the label process may be biased, and the public board is not a substitute for a frozen, leakage-controlled holdout. Before any submission can be offered, the project must have the official sample grid, shared tools, a beaten holdout baseline, duplicate checks against the registry, and a read-back validator report.
