The competition in one paragraph

DrivenData competition 306 (DOE GEMS Prize) asks for a raster of geological faults indicative of geothermal resources over a Great Basin study area. You upload a single GeoTIFF; the score is a distance-weighted Tversky index (DTI) with α = 0.2, β = 0.8 and a 300 m triangular support kernel, computed by the organizer. See the official problem description and the official rules PDF.

What the file must look like

  • single band, float32, EPSG:32611, 100 m, shape 3730 × 3292, transform (100, 0, 243350, 0, -100, 4508550) — identical to the official sample grid;
  • every pixel either finite in [0, 1] (our policy: all-finite, zeros outside the footprint) or, in the diagnostic variant only, NaN outside the footprint;
  • no NaN or sentinel inside the footprint, no negative values, no values above 1.

A previous upload of a different project's raster was rejected with "Predicted values must be in range [0, 1]". The cause was never proven, so the project ships the strict all-finite encoding as primary and records the NaN variant as diagnostics only.

Exact upload steps (once a run clears the gate)

  1. Open the submissions page and choose New submission.
  2. Confirm the site banner says CLEARED and that the sha256 on this page equals the sha256 of the file you downloaded (certutil -hashfile on Windows, shasum -a 256 on macOS/Linux).
  3. Upload the -zeros GeoTIFF (or a .zip containing exactly that one GeoTIFF).
  4. Paste the note listed on this page (≤ 140 characters) into Note (optional).
  5. Submit, then copy the receipt/score the portal shows into registry/run-card.json as ORGANIZER-CONFIRMED evidence tied to that exact sha256.

Nothing on this site performs an upload, requests credentials, or automates the competition host; the steps above are manual by design.
