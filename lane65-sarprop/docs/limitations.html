Limitations of the result as it stands

  • The holdout DTI is a relative instrument. It scores withheld catalogue pixels only. It ranks arms; it does not predict the leaderboard. Any sentence that compares 0.068 with 0.28 is wrong, and none is written on this site.
  • One draw, one seed. Seed 2026, hide fraction 0.20, one blocked partition. There is no confidence interval across draws, so the gate delta (+0.0052 overall) has no error bar. A multi-seed sweep is the single highest-value addition to the evidence.
  • The propensity field is weakly informative. Its terciles separate withheld truth only 933 : 1,709 : 4,245 across thirds. The EM convergence trace oscillates in the last four iterations (log-likelihood about 0.3%, propensity about 0.35%), which is consistent with the method's own non-identifiability and is why the stopping rule needs both conditions.
  • The scale of the propensity is not identified. kappa in {0.5, 1, 2} is reported rather than estimated; only the default is published.
  • Dot budget transfer is by count, not by density. It is justified here because the holdout's scored area and the live scored area are within 0.3% of each other (5,117,745 vs 5,114,183 cells), but a future lane on a different mask would need its own transfer argument.
  • The truth set size used in the 0.2778 analysis is inferred (~14,143) from the two receipts' arithmetic. An organizer confirmation would replace an inference with a fact.
  • Uniqueness scope is the indexed public inventory, and 2 of 655 could not be read. 653 rasters were compared, all hash-checked; the two failures are a CRS mismatch, not a match (IR-65-02), so the claim is "not a duplicate of anything checked", no more. Private, unlinked or never-published files cannot be ruled out.
  • The parallel-run stop rule needed a density correction to be interpretable (IR-65-01). As literally written it fired for 58 of 653 rasters and every firing is at or below its own uniform null; the published verdict rests on the rank correlation and the dot-set Jaccard instead. Until an owner rules, both readings are kept.
  • Only one hypothesis has been tested, and only as an emission-level blend. The thermal-fluid pathway was rejected, but the test varied the blend weight and nothing else: the kernel width, the geothermal temperature threshold and the alternative of a full feature refit were not explored, so the negative result is scoped to that one mechanism, not to the layer in general.
  • The highest-expected-gain hypothesis could not be run here. The USGS Quaternary Fault and Fold Database is the organizers' own scored-label source, and 44.7% of its in-footprint traces sit more than 300 m from any catalogue pixel, but USGS hosts are unreachable from this sandbox (egress is GitHub and PyPI only), so rank 1 of the register is prior only, never validated.
  • Nobody has confirmed this file on the portal. Until a submission receipt exists, the only claim is local validation.

Remaining work, in priority order

  1. Spend one weekly slot on this file and record the receipt. Everything else is secondary to a real number. The submitted name and note are fixed in the download card; copy the returned score and submission id into evidence/ and the feed will show it as ORGANIZER evidence.
  2. Multi-seed the gate. Re-run the arm comparison over at least three draw seeds and report the gate delta with an interval, so promotion does not rest on one partition.
  3. Unit tests for the new code. tests/test_pu.py (synthetic SAR recovery with a known propensity, already validated interactively at corr 0.98) and a test that pins the emission rule's invariants: dots at least 3 px apart, zero mass on the catalogue, all-finite output.
  4. Push coverage, not budget. The ceiling computation says the score is limited by distinct structures recovered. Work the ranked register on Hypotheses in order rather than adding dots.
  5. Run rank 1 of the register from a network-capable machine. Fetch the USGS Quaternary Fault and Fold traces, rasterise to the 100 m grid, subtract the catalogue, and put the complement through the same gated arm test used here. The prior is already measured and the promotion rule is already fixed, so this is a bounded job, not an open question.
  6. Owner rulings still open: IR-58-08 (two uniqueness regimes when a prior is itself sparse) and IR-S6-01 (whether soft priors may be diluted toward a "dot" convention). Both change what "duplicate" means for a future lane, neither blocks this file.

Bugs found and fixed in this lane, recorded so they are not reintroduced

  • Monotone log-likelihood stopping. The M-step is a weighted ERM, so log-likelihood oscillates; requiring strict improvement never terminates. Both log-likelihood and propensity must settle.
  • Design-width mismatch. The classifier design is 19 bands + 5 covariates = 24 columns, so the parameter vector is 25 long. A reshape to 20 raised a size error mid-run; the grid scorer now guards the width explicitly.
  • Placeholder covariates in the live path. The first gate run standardised the live grid with dummy mean 0 / sd 1 while the model was trained on real statistics. That would have scored a different field than the one that was validated; the live path now refuses to run without the persisted statistics.
  • Null propensity coefficients. The EM persisted coef_e=None, which silently disabled the tercile half of the gate. Fixed and re-run; the terciles are now populated and the field is persisted as an artifact.
  • Bar-budgeted emission. A marginal bar that cannot fail on a flat field drains noise. Superseded by the measured price curve plus non-maximum suppression.
