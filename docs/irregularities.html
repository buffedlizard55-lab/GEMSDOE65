At the start of this lane the tracked tree contained only README.md; the merged repository now adds project docs, a static site, and a presence-only readiness audit. It still has no competition inputs or required shared evaluator/writer. The previously mentioned download command is not present. No model or TIFF was created.

A public sibling repository has differently named block/emission code, but it is not the mandated buffered whole-segment hide-and-recover evaluator.   3. The named H33 score attribution is unsupported. The GEMSDOE32 page labels its named H33 TIF “UNSCORED”; its manifest entry has no receipt. The public leaderboard is participant-level and does not identify a file. Without an organizer receipt tying the exact artifact to a score, neither the attribution nor an explanation of that file's score is established.
  4. User-reported leaderboard values conflict and are not file receipts. The prompt includes different claims about current leaders and public scores, and some dates are later than this review date. This project does not publish a copy of leaderboard rows. Use only an authorized method to view the official board, and use a submission-page receipt for file-level score attribution.
  5. Leaderboard automation was removed after a Terms-of-Use review. The DrivenData Terms of Use prohibit automated site access for monitoring/copying and manual monitoring/copying without prior written consent. No such permission or official API is available in this checkout. A scheduled fetch/parser and mirrored rows were removed; the site now links out only. Do not reintroduce polling, scraping, or a snapshot without authorization.
  6. The “about 25% at 1:24,000” literature statement is verified but narrowly scoped. Giddens & Faulds (2025) says about 25% of its approximately 499,178 km² INGENIOUS study area was mapped in sufficient detail (e.g. 1:24,000). This is a study-specific mapping limitation, not a measurement of competition-footprint coverage or an exhaustive-map anchor.
  7. A quadrangle grid is not an exhaustive map-coverage mask. The USGS 7.5-minute map-index polygons describe map frames; NGMDB records publication footprints and scale. Neither by itself proves that all faults in a quadrangle were exhaustively mapped. No such complete mask has been audited against the exact competition footprint.
  8. Requested propensity bands may not be present in the official stack. The public task description lists elevation/slope, gravity, strain, conductivity, magnetic, and earthquake features, but does not explicitly guarantee a LiDAR-coverage mask, range-front distance, local-relief raster, or basin-depth proxy. No local stack exists to inspect.
  9. Gravity-source overlap is unresolved. A USGS CC0 Great Basin hydrogeologic data release includes a gravity-derived depth-to-basement surface, but its study is predominantly eastern Nevada and western Utah and its model nodes are one mile apart. No exact overlap, alignment, or suitability test against the GeoDAWN footprint/grid has been run; it remains a research lead.
  10. Several user-supplied dates are future-dated. The pasted result list includes 2026-10-12 entries, after this review date (2026-10-11 UTC). Treat them as unverified, not current evidence.
  11. No uniqueness, leakage, holdout, or format validation was run. There is no local prior-raster registry, candidate surface/dot set, evaluator, or TIFF. Correlation, 3-pixel overlap, one-feature AUC, HOLDOUT-DTI, CI, raster hash, and validator output are all not computed/not run.
  12. Published-site state still requires post-merge confirmation. A Pages configuration existed before this branch was updated; verify the published URL and confirm the workflow deploys the docs/ site before claiming the changes are live.
