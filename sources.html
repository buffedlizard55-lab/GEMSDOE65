Source register · scope and caveats

Official sources for review

Each link is paired with what it supports and what it does not prove. Scores and model claims are kept separate from primary-source facts.

Competition and submission

  • DrivenData problem description — task, official feature families, metric, and GeoTIFF output contract. The predictor is geological fault presence, not vents themselves.
  • DrivenData data page — official files. In this review it redirected to login; no data were downloaded.
  • Live official leaderboard — public results are time-sensitive, not private holdout or a submission receipt.
  • DOE/NLR GEMS Prize official rules — official contest rules for manual review.
  • DrivenData reference solution — organizer baseline and workflow starting point, not evidence that this repo has run it.

Primary literature and geology

  • Bekker & Davis, PMLR 94 (2018) — SAR PU assumption and EM method.
  • Bekker, Robberechts & Davis, arXiv:1809.03207 — propensity-aware empirical risk and unknown-selection discussion.
  • Giddens & Faulds (2025), SGP-TR-229 — Great Basin step-overs, range-front association, and explicit visibility-bias caveat. The study statistic is not a universal fault prevalence estimate.

Official geospatial data

  • USGS GeoDAWN data release — airborne magnetic/radiometric products and coordinated LiDAR coverage documentation; CC0-marked release.
  • USGS 3DEP Lidar Explorer and 3DEP Lidar Point Cloud catalog record — public coverage/data source. No alignment was performed here.
  • USGS Data Series 249, Geologic Map of Nevada — includes 7.5-minute quadrangle geometry/index information; not a guarantee of exhaustive fault mapping.
  • USGS National Geologic Map Database — map publication records with area and scale metadata; a catalog is not a completeness certificate.
  • USGS Nevada magnetic and gravity data (DS-234) and USGS Great Basin geoscience data base — official candidate sources if the gravity-derived basin-fill proxy is missing. No grids were downloaded or harmonized in this review.
Unverified mapping-coverage claim: “about 25% of the region has detailed 1:24,000 mapping” has not been substantiated by the official materials checked here. The quadrangle grid and map catalog are available, but completeness must be proven before they anchor propensity scale.
